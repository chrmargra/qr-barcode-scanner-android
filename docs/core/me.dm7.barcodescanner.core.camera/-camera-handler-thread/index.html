CameraHandlerThread

open class CameraHandlerThread(scannerView: BarcodeScannerView) : HandlerThread

Background thread used to open a camera without blocking the Android main thread.

The thread starts during construction. Camera-open results are delivered back to the associated BarcodeScannerView on the main thread.
